# Sheriff 0.5.0

A new name (D194): the sheriff decides who's welcome in town. Nothing else changes in how it works.

## Installing over the previous version

With the server stopped:
1. Rename its plugin folder to `plugins/Sheriff`.
2. Rename its permission in LuckPerms to `sheriff.approve`.
3. Use `/sheriff` for the console commands.
4. Swap in `Sheriff-0.5.0.jar`.

Leaf Juice needs its matching update to find Sheriff.

## Tested

Unit tests pass. The rename was checked on a throwaway server.
